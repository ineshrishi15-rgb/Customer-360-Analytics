## Project Overview

This project uses Python and pandas to integrate customer, product, and transaction datasets into a unified analytical view. It explores customer purchasing behaviour, transaction patterns, sales performance, and customer segmentation.

## Analysis Areas

- **Customer Analysis:** Explore purchasing activity, customer-level metrics, and spending behaviour.
- **Transaction Analysis:** Examine transaction records, sales patterns, and purchase frequency.
- **Product Analysis:** Analyse product-level information and purchasing trends.
- **Customer Segmentation:** Group customers using rule-based classifications derived from purchasing behaviour.

## Tools Used

- Python
- pandas
- NumPy
- Jupyter Notebook
- Data Cleaning and Feature Engineering
- Exploratory Data Analysis (EDA)

## Key Features

- Integration of customer, product, and transaction datasets using pandas joins
- Identification and removal of duplicate transaction records
- Customer-level feature engineering and aggregation
- Rule-based customer segmentation
- Exploratory analysis of customer purchasing behaviour

## Business Objective

The goal is to develop a consolidated customer analytics framework that helps businesses understand purchasing patterns, identify customer groups, and support data-informed marketing and customer management decisions.

## Files

- `Customer_360_Analytics.ipynb` — Python notebook containing data processing, customer analytics, and segmentation workflows

## How to Use

1. Download the `.ipynb` file from this repository.
2. Open it using Jupyter Notebook or Google Colab.
3. Ensure the required Python libraries and input datasets are available.
4. Run the notebook cells sequentially to reproduce the analysis.
